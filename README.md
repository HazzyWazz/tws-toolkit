# TWS Toolkit

A collection of hand-made tools to use with The Wolf's Stash mobile app.

## e621-api (library)
A GET-only library to be used with the projects within

## tws2pool

(not ready)
Downloads all saved `pool:`s from a saved searches export

## tws2tag

Fetches and downloads the JSON data of downloaded posts.

## tagfilter

(not ready)
Selects posts and pools which are not in a specified tag blacklist.
